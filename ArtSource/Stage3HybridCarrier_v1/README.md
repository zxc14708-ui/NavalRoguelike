# 3스테이지 항공전함 — 모델 시안

사용자가 첨부한 두 이미지의 전방 포탑·중앙 함교·후방 항공갑판 구성을 바탕으로 새로 제작했습니다. 함수에 2연장 포탑 2기(총 4문), 비행갑판 가장자리 돌출 받침에 좌현 3기·우현 3기의 대공포를 배치했습니다. 중앙 활주로를 비워 두었습니다.

- `Models/EnemyHybridBoss.fbx`: 모델 원본 길이 16m. Blender +Y 전방/+Z 위, FBX -Z Forward/Y Up, 게임 기존 2배 기준 약 32m. 설계 수면선은 모델 높이 0.
- 비행갑판 길이 8.47m(게임 기존 2배 기준 약 17m), 전체 선체 길이의 약 53%.
- `Stage3HybridCarrier.blend`: 편집 원본. 선체, 갑판, 함교, 주포 선회·고각부, 대공포 선회·고각부를 따로 유지합니다.
- `Preview/`: 함수 사선·함미 사선·상면 렌더. `manifest.json`: 치수·삼각형 수.

주포는 `MainGun_01/02` → `MainGun_Elevation_01/02` → `MainGun_Muzzle_01~04`입니다. 양현 대공포에는 `AA_Port_01~03`, `AA_Starboard_01~03`과 각 포구가 있습니다. `AAMount`는 기존 단일 대공 포구 규약에 맞춰 우현 중앙 포구에 둔 별칭입니다. `FlightDeckLaunch`와 `RadarPivot`을 포함합니다. 기존 게임의 여러 대공포 발사 연동을 구현했다는 뜻은 아닙니다.

이번 시안은 모델 제작만 수행했습니다. 현행 보스는 주포 4기와 별도 미사일 발사대를 참조하므로, 이 모델을 채택해 게임에 넣을 때는 달라지는 무장 수와 기존 보스 패턴을 함께 검토해야 합니다. 프리팹, 씬, 런타임 코드에는 적용하지 않았습니다.
