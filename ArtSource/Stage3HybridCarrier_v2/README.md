# 3스테이지 항공전함 v2 — 주포 비율 수정

[미 해군 정보국 1945년 이세급 상면·측면도](https://commons.wikimedia.org/wiki/File:Ise_class_battleship_drawing.png)의 함수 쌍열 포탑과 같은 지점의 선폭을 눈대중으로 비교했습니다. 실제 치수를 복제한 것이 아니라 포탑이 선수 갑판을 덮어 보이지 않는 비율을 참고했습니다.

v1 대비 주포 계통의 폭은 76%, 길이는 75%, 높이는 68%로 조정했습니다. 포탑 몸체 외곽 폭은 1.48m에서 약 1.12m입니다(모델 원본 기준). 포신·받침·포구를 함께 축소했고, 두 번째 포탑은 앞 포탑보다 한 단 높은 구성을 유지합니다. 원본 길이 16m, 함미 갑판 8.47m, 함수 2연장 2기 및 대공포 좌우 3기씩은 유지합니다.

- `Models/EnemyHybridBoss.fbx`: 모델 원본 단위·소켓 이름 유지. 회전축과 포구 위치는 축소한 모델에 맞춰 구웠습니다.
- `Stage3HybridCarrier.blend`: 편집 원본.
- `Preview/`: 사선·상면·함미 렌더. v1과 카메라·배율이 같습니다.
- `validate.py`: FBX 재임포트 및 v1과의 크기 비교.

모델만 수정했습니다. Unity 프리팹, 게임 패턴과 수치에는 적용하지 않았습니다.
