# 섬·해안 시설 다양화 팩 v3 — 모델/배치 검토용

Unity 프로젝트는 수정하지 않았습니다. 모델, Blender 원본, 배치 생성기와 검증 결과를 제공합니다. 실제 인게임 랜덤 생성/광원/레이더 기능에 연결한 상태는 아닙니다. 이전 EnvironmentDetailPack은 그대로 보존했습니다.

## 변경 내용

- 바위섬: 매끈한 돔을 단차 있는 수직 절벽, 넓은 파단면, V자 균열, 각진 암반 선반으로 교체했습니다. 구형 바위를 사용하지 않습니다.
- 바위 소품: 바닥이 평평하고 모서리/상면이 불규칙하게 잘린 폐쇄 다면체로 바꿨습니다. 기존 다른 섬의 해안 바위도 교체했습니다.
- 신규 분리 소품: 레이더 기지, 고상식 해안 초소, 관측 벙커, 보급 창고. 기초·트러스·사다리·난간·문·창·지지부를 포함합니다.
- 레이더는 `RadarPivot → SearchArrayHead`, 초소는 `SearchlightPivot` 아래에 움직일 부분을 분리했습니다. 자동 회전/탐조등 광원은 아직 연결하지 않았습니다.

## 랜덤 배치 생성 과정

`Source/environment_layout.py`는 Blender/Unity에 의존하지 않는 배치 계획기입니다. 지형 높이 함수와 해안선 함수를 받습니다.

1. 테마에 맞는 핵심 시설과 보조 시설 후보를 선택합니다.
2. 바다에 걸치는 기초, 지나치게 급한 지형, 시설 간 겹침을 제외합니다.
3. 적합한 여러 후보 중 시드 기반으로 위치/방향을 선택합니다. 항상 같은 최저점으로 모이지 않습니다.
4. 시설 기초 영역을 지형에 평탄화하고, 건물은 기초 높이에 맞춰 놓습니다.
5. 소품 개수/방향과 잔교 유무를 정하고, 부표는 잔교 및 다른 부표와 겹치지 않도록 배치합니다.
6. 실제 `EntryOrigin` 위치를 기준으로 시설 사이 돌길을 연결합니다. 시설과 지형은 별도 메시입니다.

같은 테마·시드·지형 함수면 같은 배치가 나옵니다. `RULES`, `FOOTPRINTS`로 후보 시설, 개수, 확률, 여유 간격을 조정할 수 있습니다. 작은 섬에서 적합한 자리가 없으면 선택 소품은 생략하며 필수 시설이 들어갈 수 없으면 오류를 반환합니다.

4개 테마의 120개 시드에 대해 반복성·기초 육지 조건·시설 겹침을 검사했습니다. 납품된 시설 섬은 실제 FBX 지형으로 기초 중심/모서리 접지를 별도로 검사했습니다. 결과는 `layout_validation.json`입니다. 이 결과는 Blender 배치 생성 검증이며 Unity 런타임 검증은 아닙니다.

## 파일과 재생성

- Models/: 기본 20개(섬 8 + 소품 12), 추가 시드 섬 3개, 각각의 LOD1 — 합계 46 FBX.
- EnvironmentDetailPack.blend: 전체 분리 배치 원본. 개별 `ENV_*.blend`는 검사 후 원점에 저장한 모델입니다.
- Preview/: 개별 미리보기, 8종 섬 비교, 12종 소품 비교, 시드별 비교 이미지.
- manifest.json: 실제 크기·삼각형 수·팔레트·배치 좌표·기초 평탄화 영역·연결 지점.
- validation.json: 실제 FBX의 단일 루트/스케일/메시 회전/폐합/퇴화면/재질색 검사.
- Source/: 생성기와 검증기. Blender 5.2에서 제작/검증했습니다. 외부 텍스처는 필요하지 않습니다.

ZIP을 풀고 Blender를 백그라운드 실행하여 `Source/build_environment_detail.py -- --output 새출력폴더 --seed 20261099 --variants 3`를 실행할 수 있습니다. CLI seed는 추가 레이더섬 예제의 시작 시드이며, 기본 8종은 PRESETS의 고정 시드를 사용합니다. 다른 테마 배치는 `generate_layout(kind, seed, ...)` 또는 PRESETS seed 변경으로 생성합니다. 검증기는 같은 `--output` 경로를 받습니다.

## 좌표/적용 주의

- 미터 단위, Blender +Z Up / +Y Forward, FBX -Z Forward / Y Up / All Local, 단일 루트·scale1.
- 조합 섬은 루트0, 현재 바다에 맞춘 수면 Z=-0.9m, 해저 Z=-3m입니다. 추가 -0.9 오프셋을 중복하지 마세요.
- 땅 소품 바닥 중심은 Z=0. 부표/난파선 단독 파일은 흘수선 Z=0입니다. 잔교는 해안 연결 끝이 원점이며 +Y로 뻗고, 보행면은 약 Z=0.19m입니다.
- JSON 좌표는 Blender XYZ입니다. Unity XYZ로 그대로 복사하지 마세요. 임포트한 FBX의 배치 루트/자식 Transform 또는 검증한 축 변환을 사용해야 합니다.
- 카메라/빛/바다/애니메이션/콜라이더/LODGroup은 FBX에 포함하지 않습니다. 낮은 폴리곤의 제조물/바위 소품은 작은 구조를 보존해 LOD1이 기본형과 같은 세부도일 수 있습니다.
- 기존 섬 9개 재질의 이름/RGB는 유지했으며 새 재질은 ENV_ 접두사를 사용합니다. Unity 아트 임포터에 추가 재질을 등록하고 URP Lit으로 매핑해야 합니다.
- TerrainShell은 시각 메시입니다. 전체 조합 섬에 하나의 convex Collider를 씌우면 환초의 석호/오목한 해안이 메워집니다. 별도 저해상도 판정 구획이 필요합니다.
- 기존 섬은 IslandBuilder의 절차형 메시라 FBX 복사만으로 교체되지 않습니다. IslandInfo, Terrain layer13, 레이더 엄폐, 충돌/어뢰 차단, 스폰/회피 흐름을 유지하며 로더를 연결해야 합니다.
- IslandField.Remove가 모든 sharedMesh를 Destroy하는 기존 루틴은 FBX 자산/공유 메시를 넣기 전에 런타임 소유 메시만 정리하도록 수정해야 합니다.
- 기존 출항45m 비우기/수로34m/구역110m와 실제 bounds를 대조해야 합니다. 새 시설과 부표의 외곽은 기본 지형 반경보다 넓을 수 있습니다.

레이더 기지/벙커는 현재 장식입니다. 적 탐지, 파괴 가능한 시설, 보급 보상 같은 게임 효과를 추가한 것이 아닙니다. 미리보기 바다와 광원도 게임 그래픽 수정 결과가 아닙니다.

## 게임 적용 상태 (2026-10-02, Claude)

- FBX(LOD1 제외)를 `Assets/_Game/Art/Models/Environment/Islands·Props`에 복사, 에디터 `NavalEnvironmentArtBuilder`(메뉴 Naval/Art/Build Environment Prefabs)가 `Resources/Environment/Islands·Props/ENV_*.prefab`을 만든다.
- 자동 생성 섬의 일부(바위섬 35%·무인도 65%)가 이 모델 섬으로 나온다. 판정은 지형 셸 정점으로 만든 볼록 조각 60개(환초 석호는 둘러싸인 못이라 메움), 잔교·방파제·어선·부잔교·해식 아치는 상자 판정.
- 해안 소품(어선·부잔교·방파제·해식 아치·해변 어구·부표)은 자동 생성 섬 둘레에 확률로 놓인다. 레이더·풍속계 회전, 탐조등 흔들림, 부표·어선 출렁임, 등대 불빛 연결.
- 레이더 기지·벙커의 게임 효과(탐지·파괴·보상)와 LODGroup은 아직 없다. 자세한 내용은 `ARCHITECTURE.md` "섬(엄폐)" 절.
