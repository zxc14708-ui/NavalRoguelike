# 시작 화면 군항 구획 및 예인 연출

Unity 6000.3.23f1의 시작 화면 군항을 개정했습니다. 작업과 검수에는 원본의 별도 복사본을 사용했습니다.

## 구역과 진입로

| 구역 | 변경점 |
| --- | --- |
| 생활단지 | 관사에서 숙소 단지로 이어지는 보행로, 간선 횡단보도, 숙소 블록 사이 연결, 주차장 출입구 |
| 항공대 | 활주로 연결 유도로 접속면과 대기선, 서비스 구역 표식과 주차장 게이트 |
| 함정 정비단지 | 안벽 진입로와 작업 도크를 잇는 동선 및 정비구역 표식 |
| 해군 작전구역 | 사령부 진입로와 보도, 경계 펜스와 함대 사령부 표식 |
| 서쪽 보급 구역 | 간선과 컨테이너 야적장을 잇는 T자 접속부, 화물 게이트, 예인선 전용 계류지 두 자리 |

사령부 3곳, 숙소, 서쪽 특수전 시설, 비행장의 주차장에 진입로를 만들고 중앙 통로를 비웠습니다. 레이더돔 아래 언덕은 돔 높이를 유지하면서 도로 쪽 사면을 줄였습니다. 현재 4개 시작 함선 선택 위치와 기존 전투기·초계기 경로는 유지합니다.

## 예인 연출

화물선이 하역하는 동안 두 예인선이 전용 계류지에서 출발합니다. 우현 함수와 함미에 각각 줄을 연결합니다. 선미가 돌제 끝과 여유 거리를 벗어나면 함미 예인선이 먼저 이탈하고 함수 예인선이 뒤따릅니다. 두 예인선은 전용 계류 자리로 돌아가고 화물선은 외해로 자력 항해합니다. 입항 때 두 척이 다시 나와 접안을 돕고, 136초에 재계류한 뒤 하역 주기를 이어갑니다. 전체 주기는 170초입니다.

화물선 통과 수역과 겹치던 순찰정 서쪽 복귀로를 바깥쪽으로 옮겼습니다. 기존 북쪽 군함 선택 정박지는 그대로입니다.

## 반영

현재 게임과 같은 버전의 프로젝트에서 `HarborDistricts_v2.unitypackage`를 가져오면 시작 화면에서 바뀐 배치와 연출이 적용됩니다. 패키지에는 시작 화면용 두 프리팹, 새 전용 메시, 군항 운영 메시와 관련 소스만 들어 있습니다. 기존 팔레트와 `HarborFacilityDetails`를 참조합니다. 편집기에서 다시 생성하려면 **Naval > Art > Build Harbor Menu Backdrop** 실행 후 **Naval > Art > Build Harbor Operations Overlay**를 실행합니다.

## 검수

`Screenshots`에 시작 화면 렌더와 각 위치 확대본이 있습니다. `UnityValidation.txt`에 실제 복제 메뉴를 생성해 검사한 결과가 있습니다. 도로 연결부는 생성된 메시 표면을 추적해 확인했고, 선박 검사는 선체 외곽 상자와 예인줄을 일정 간격으로 샘플링했습니다.
