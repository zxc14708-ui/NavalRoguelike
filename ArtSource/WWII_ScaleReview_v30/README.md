# WWII 플레이어 블록 비율 조정 v30

2026-10-17. 함교 대비 양용포가 크게 보인다는 피드백에 따른 모델 조정본입니다. 게임에는 적용하지 않았습니다. v29의 실제 자료·소켓 연결 안내는 `../WWII_ModePack_v29/README.md`를 참고합니다.

| 항목 | v29 | v30 |
|---|---|---|
| 함교 폭 × 길이 × 높이 | 1.70 × 5.48 × 2.715m | 동일 |
| 플레이어 양용포 폭 | 1.424m | 1.111m |
| 양용포 전체 길이(포신 포함) | 2.800m | 2.184m |
| 양용포 높이 | 1.165m | 0.909m |
| 양용포 폭 / 함교 폭 | 83.8% | 65.3% |
| 대공포 가동부 크기 | 100% | 86% (고정 방호 진지와 받침은 동일) |
| 어뢰관 가동부 크기 | 100% | 88% (고정 갑판과 선회 링은 동일) |

적 함선·항공기·발사체 전체 치수도 manifest로 확인했습니다. 이번 조정은 플레이어 블록의 시각적 비례에 한정됩니다. 적 순양함의 큰 주포에는 축소를 적용하지 않았습니다. 이는 실제 무기 치수의 축척 재현이 아니라 2m 게임 격자 안의 시각적 조정입니다.

`Models/`에는 조정된 블록을 포함한 전체 14종을 보관합니다. 좌표·소켓 위치와 메시 좌표를 함께 변경했고 객체 scale은 모두 1입니다. `validation.json`은 조정 FBX를 다시 읽어 원점·단위 스케일·블록 규격·필수 소켓을 확인한 결과입니다.

- `Preview/DualGun_Before_After.png`: 왼쪽 기존, 오른쪽 축소본. 같은 카메라·배율.
- `Preview/WWII_PlayerDestroyer.png`: 현재 시작 배치 조립 시안.
- `WWII_ScaleReviewed.blend`: 수정본 원본.
- `manifest.json`: 전체 모델의 최종 실제 경계상자와 소켓.

런타임 프리팹·공격 수치·충돌체는 수정하지 않았습니다. 이 모델을 채택하면 v30의 블록 파일을 사용해야 합니다.
