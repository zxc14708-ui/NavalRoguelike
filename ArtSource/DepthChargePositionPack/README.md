# 위치별 폭뢰 모델 2종 — 검토용, 게임 미적용

기존 군함 회색·미니어처 스타일로 제작한 1×1 블록 모델입니다. Unity 프로젝트의 모델, 프리팹, 코드와 재질은 변경하지 않았습니다.

| 배치 | 모델 파일 | 형태 |
| --- | --- | --- |
| 선미·후방이 열린 자리 | `Models/MOD_DepthChargeRack.fbx` | 기존 변경판을 바탕으로 한 경사 레일 2열, 원통 폭뢰 4개, 투하 레버 |
| 좌현·우현이 열린 자리 | `Models/MOD_DepthChargeProjector.fbx` | 짧은 경사 투사기 위에 폭뢰를 얹은 측면 발사대 |

## 포함 파일

- `Models/`: FBX와 GLB. 카메라·조명·텍스트·미리보기 화살표는 포함되지 않습니다.
- `Blender/`: 각 모델의 편집용 중립 상태 `.blend`와 별도의 미리보기 장면.
- `Preview/`: 각각의 렌더와 비교 이미지.
- `Sources/`: 재생성 스크립트와 독립 검증기.
- `manifest.json`: 실제 크기, 삼각형 수, 소켓 계층, 분리 가능한 폭뢰 그룹.
- `validation.json`: 내보낸 FBX를 다시 불러와 확인한 결과. Unity 런타임 검증은 아닙니다.

## 규격과 방향

- 셀 2m, 모델 평면 크기 1.8×1.8m 이내, 높이 0.9m 이하, 900 tris 이하.
- 단일 중심 루트, 바닥 Blender Z=0. 메시 회전은 적용되어 있고 scale은 1입니다.
- Blender +Y=함선 전방, +Z=위. FBX는 -Z Forward / Y Up / All Local 설정으로 내보냅니다.
- 이 패키지의 발사 소켓 방향 계약은 **Blender 소켓 로컬 +Y**입니다. Unity 연결 시 기존 모델 축 보정과 함께 변환해야 하며, 확인 없이 Unity `Transform.forward`(+Z)와 같다고 가정하면 안 됩니다.

## 추후 게임 연결 시

현재는 모델·소켓만 준비되어 있습니다. 위치 판정, 궤적, 재장전, 폭발, 사거리·피해·쿨타임과 투하 애니메이션은 구현하지 않았습니다.

1. 선미 쪽 인접 셀이 비어 있고 선체 외곽이면 투하대를 선택합니다. 레일 출구는 Blender -Y입니다.
2. 좌·우 측면이 열려 있으면 측면 발사대를 선택합니다. 기본 모델은 +X 방향으로 발사하며, 반대편은 모델 마운트의 갑판 수직축 기준 180° 회전으로 배치합니다. 음수 스케일은 필요하지 않습니다.
3. 선미·측면이 동시에 열린 모서리의 우선순위와 함내 배치 허용 여부는 아직 결정되지 않았습니다. 막힌 방향으로 폭뢰가 이웃 블록을 관통하지 않게 별도 판정이 필요합니다.
4. 후방 `StoredCharge_01`~`04`, 측면 `LoadedCharge_01`~은 루트 바로 아래의 독립 그룹입니다. 투하·발사할 때 해당 그룹만 이동하고 받침·레일·지지대는 고정합니다.
5. 후방 `LaunchPoint_01/02`는 첫 번째 레일 출구, `03/04`는 두 번째 레일 출구입니다. 저장 탄 4개와 물리적인 출구 2개를 구분합니다. `DropPoint_01/02`도 제공합니다.
6. 기존 `MOD_AswLauncher.fbx`를 덮어쓰지 않았습니다. 새 이름을 선택하는 모델 로더·프리팹 연결이 필요합니다.

## 실제 형태 참고

- [USS SLATER 선미 폭뢰 투하 레일](https://ussslater.org/depth-charge-racks)
- [USS SLATER 측면 K-gun 폭뢰 투사기](https://ussslater.org/kgun)

역사적인 설비의 구분 가능한 실루엣을 현재 게임 스타일에 맞춰 재해석했습니다. 실제 장비의 정확한 치수 복제나 현대 해군 운용 장비라는 주장은 아닙니다.

## 재생성

Blender 백그라운드에서 `Sources/build_depth_charge_positions.py`를 실행합니다. `-- --output 출력폴더`를 지정할 수 있습니다. 실행 후 `Sources/validate_depth_charge_positions.py`를 같은 출력 경로로 실행하면 FBX 재임포트 검증 결과가 생성됩니다.
