# 적 등급과 잠수함 교전 규칙

## 등급 (2026-09-26)

`EnemyDefinition.Rank`는 적의 역할 분류다. `TargetCategory`(무기 효율·표적 가치)와 별개이며, 등급만으로 체력·피해·보상을 곱하지 않는다. 수치는 각 적 데이터에서 개별 조정한다.

| 등급 | 적 | 교전 역할 |
| --- | --- | --- |
| 일반 | 고속정, 미사일정, 자폭 드론, 정찰기, 전투기 | 자주 등장하는 기본 압박. 서로 다른 방어 수단을 요구 |
| 엘리트 | 잠수함, 순항미사일 잠수함, 엘리트 초계함 | 드물게 등장하는 우선 대응 표적. 잠수함은 대잠 장비, 초계함은 사각 기동 요구 |
| 보스 | 중형 함정, 항공전함 | 각 스테이지의 마지막 구간에 고정 등장 |

1스테이지에는 일반 3종(고속정·미사일정·드론), 엘리트 1종(잠수함), 보스 1종이 있다. 2스테이지에서 정찰기·전투기·순항미사일 잠수함·엘리트 초계함·항공전함이 추가된다. 기존 적도 계속 출현한다.

## 잠수함의 위협과 대응

문제: 잠항 모델의 함교탑이 수면 위에 보여 “보이지만 함포로 공격할 수 없는 적”처럼 느껴졌다. 이제 잠항 중인 선체는 렌더링하지 않는다. 어뢰 준비 경고, 날아오는 어뢰, 발사 위치의 일시적인 추정 표식으로 위협을 알린다. 수색에 성공하면 **실제 선체가 아니라 소나 접촉**이 레이더에 표시된다. 수중 접촉은 여전히 일반 함포·대함미사일의 표적이 아니다.

1. 잠항 접근: 선체·항적은 보이지 않는다. 잠수함은 잠항한 채 사격 제원을 잡는다.
2. 공격 예고: 어뢰 잠수함은 발사 1.2초 전에 “어뢰 준비” 경고와 작은 물거품을 보여 준다. 플레이어는 그때 속력이나 침로를 바꿔 제원 사격을 피할 수 있다.
3. 발사: 어뢰 자체는 보이고 경고된다. 잠수함의 **발사 당시 위치**만 6초 동안 수색 단서로 남으며, 이동 중인 현재 위치를 공개하지 않는다.
4. 반격: 소나가 반경 안의 표적을 수색하며, 쿨타임마다 능동 핑을 자동 발동해 접촉을 확정한다. 헬기는 발사 흔적을 따라 수색하고 자체 센서로 접촉을 확정한다. 접촉 후 폭뢰·VLS 대잠 경어뢰가 수중 표적을 공격한다.
5. 순항미사일 잠수함은 잠망경을 올리는 준비·발사 동안 잠깐 보인다. 발사 직후 다시 잠항하고 5.5초 동안 마지막 발사 위치만 남긴다. 발사된 미사일은 기존 대공·기만 방어 체계로 막을 수 있다.

### 이번 밸런스 변경

| 항목 | 이전 | 현재 |
| --- | ---: | ---: |
| 어뢰 잠수함 한 발 피해 | 28 | 42 |
| 어뢰 잠수함 등장 가중치(해당 라운드) | 0.8 | 0.35 |
| 순항미사일 잠수함 등장 가중치(2스테이지 4·6·7구간) | 0.5 / 1.0 / 1.2 | 0.25 / 0.45 / 0.55 |
| 어뢰 발사 위치 단서 유지 | 3초 | 6초 |

가중치는 해당 라운드의 **상대적 선택 확률**이다. 전체 스폰 속도를 곱하는 수치가 아니며, 보스 고정 스폰에도 영향을 주지 않는다. 어뢰 재장전 10초와 사격 예고 1.2초는 유지했다.

### 플레이 테스트 때 확인할 점

- 소나/헬기 없이도 경고를 보고 조함으로 어뢰를 피할 수 있는가? 42 피해가 너무 높으면 36~40으로 낮춘다.
- 발사 흔적을 따라 헬기가 수색할 충분한 시간이 있는가? 부족하면 단서 유지 시간을 8초로 늘린다.
- 처음 잠수함이 나오는 1스테이지 6구간 전에 대잠 대응 카드가 한 번도 제시되지 않는 경우가 있는가? 자주 발생하면 소나·헬기·폭뢰 중 하나를 앞선 레벨업 카드에 보장하는 규칙을 추가한다.
- HUD에서는 소나 접촉을 수상 표적과 다른 기호로 유지해야 한다. 접촉 표시가 일반 함포로 공격 가능한 실체처럼 보이면 혼란이 재발한다.
