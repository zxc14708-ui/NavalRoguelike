# 블록 시너지 (항모 데크 제외)

작동 중인 블록의 **점유 칸**이 상하좌우로 맞닿을 때만 활성화된다. 관련 블록이 파괴되거나 제거되면 해제된다.

| 배치 | 효과 |
| --- | --- |
| 헬기데크 2개 인접 | 두 데크의 헬기가 각각 출격한다. 두 번째 데크는 최초 출격을 1초 늦추며, 귀환 후 재출격 대기시간 -20%, 목표가 없을 때 수색 8→12초. 피해량은 그대로. |
| 레이더에 SAM과 CIWS가 각각 인접 | 연결된 SAM은 16m 바깥의 미사일을 먼저 맡는다. 바깥 표적이 없으면 안쪽도 교전하며, 충돌까지 2초 이하면 안쪽 표적도 우선순위 제한 없이 교전한다. CIWS의 기존 근접 교전은 유지한다. |
| 소나에 헬기데크 또는 폭뢰 발사기 인접 | 소나 접촉 확정 2→1.2초, 접촉 유지 6초. 기존 헬기 잠수함 우선순위와 폭뢰의 접촉 위치 선행조준을 활용한다. |
| 76mm–탄약고–76mm 일직선 | 각 포의 탄약 보급 배율에 +10%p(총 1.35배 상한). 한 포가 발사하면 다른 포의 발사를 유효 재장전 시간의 절반만큼 지연해 교차 사격한다. 피해량은 그대로. |
| 전자전 장비와 기만체 인접 | 교란 지속시간 +20%, 기만체 유인 반경 +15%. 준비된 기만체는 적 대함미사일의 예상 충돌 시간이 3초 이하일 때 자동으로 발사된다. |
| 손상통제반에 다른 블록 2개 인접 | 인접 구획의 탄약고 유폭 피해 -25%, 모듈 지속 수리량 +15%. 직격탄은 감소시키지 않는다. 원래 제안의 장갑 블록은 현 규격에서 삭제되어 이 조건으로 변경했다. |

이 수치는 프로토타입 기준이다. 실제 전투에서 과도한 자동 방어, 기만체 소모, 탄약고 유폭 방호의 체감도를 플레이테스트한 후 조정한다.
