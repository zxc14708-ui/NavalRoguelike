# Codex 모델링 요청 — 지원 블록 · 지원 함정 (2026-11-22)

작성: Claude. 기능 설명은 `ARCHITECTURE.md` 2026-11-22 "지원 블록 개편" 줄.
아래 대상은 게임에 들어가 작동하지만 지금은 **기본 도형으로 지은 임시 외형**이다.
코드 · 데이터 · 프리팹 연결은 Claude가 한다. Codex는 **모델(FBX) · 원본 · 비교 이미지**까지만.

우선순위: **A(지원 함정 — 보급선 3단계 · 고속정) → B(지원 블록 4종) → C(정찰 드론)**.
A가 화면에 가장 크게, 가장 자주(35~45초마다 15~20초) 보인다.

---

## 0. 공통 규칙 (`CODEX_MODEL_REQUESTS_DAYNIGHT_2026-11-19.md` 0장과 같음)

- 다른 코드 · 에셋을 덮어쓰지 말 것. 관련 없는 프리팹 · 씬을 일괄 재생성하지 말 것. enum 순서 변경 금지.
- **단위 · 축**: 1 유닛 = 게임 1m. 앞 = +Z, 위 = +Y. FBX는 기존 모델과 같은 방식(Blender `apply_scale_options='FBX_SCALE_NONE'`, 유니티 루트 배율 100).
- **재질**: 새로 만들지 말고 기존 팔레트 이름(`Assets/_Game/Art/Models/Materials`, 블록은 `Assets/_Game/Art/MAT_art_*`). 텍스처 없음(재질 색만).
- **스타일**: 낮은 폴리곤 · 각진 면. 기존 시작 함정 블록(`Prefabs/StartingShips/Blocks/BLK_*`)과 같은 결.
- **함정 원점** = 수면선 높이의 함 중심(모델 y 0이 물 높이), 흘수 0.3~0.4m.
- **결과물**: `ArtSource/SupportPack_v1/`(blend · build 스크립트 · manifest.json · 비교 PNG) + FBX. 유니티 가져오기 검증은 별도 검증 프로젝트에서.
- **비교 이미지**: 모델마다 2장 — 비스듬한 뷰, 전투 카메라처럼 위에서 본 뷰. 함정은 기함(약 16m) 실루엣 옆에, 블록은 2m 격자 칸 위에.
- **아군 표시**: 지원 함정 · 드론은 아군이다. 적 붉은 띠(`Emergency Red`)는 쓰지 말 것. 보급선은 주황 보급 띠(`Warning Yellow` 계열), 고속정은 청록 띠.

## A. 지원 함정 (전투단 통신 중계가 부른다)

**흐름**: 블록 단계마다 35~45초마다 기함 뒤 약 55m에서 나타나, 보급선은 기함 **왼현에 나란히**(옆 간격 약 3m) 붙어 15~20초 보급하고, 고속정 편대(2 · 4 · 6척)는 기함 둘레 자리에서 따라오며 기관포를 쏜다. 끝나면 바깥쪽으로 빠져 사라진다. 표적이 아니다(맞지 않음).

### A-1. 보급선 3단계 — `SUP_SupplyShip_L1` · `_L2` · `_L3`

지금: `Scripts/Modules/Runtime/SupportFx.cs` `BuildSupplyShip(level)`(상자 · 원기둥).

| 단계 | 모습 | 길이 · 폭 | 꼭 보일 것 |
|---|---|---|---|
| L1 | 소형 군수 지원정 | 약 11m × 3.2m | 앞쪽 화물 갑판(컨테이너 · 팔레트), 작은 기중기 1, 뒤쪽 낮은 함교 |
| L2 | 중형 보급함 | 약 15m × 4.0m | 보급 기둥(킹포스트) 1쌍과 가로대, 연료 탱크/화물창, 함교 |
| L3 | 대형 군수 지원함(AOE급 느낌) | 약 19m × 4.8m | 보급 기둥 2쌍, 함미 헬기 갑판(흰 원), 굴뚝, 높은 함교 |

- 셋이 **같은 계열 배가 커지는 것**으로 읽히게(같은 색 · 같은 띠 · 같은 함교 모양).
- 보급 기둥에서 **왼현(-X)** 쪽으로 호스 붐이 나와 있게(기함이 오른쪽에 있다).
- **필수 빈 노드**:

| 빈 노드 | 위치 | 쓰임 |
|---|---|---|
| `TransferPoint` | 왼현(-X) 보급 붐 끝, 갑판 위 약 1.6m | 연료 호스 · 화물 줄이 여기서 기함으로 건너간다 |
| `SmokePoint` | 굴뚝 꼭대기(L3, 선택) | 배기 연기 |
| `LampPoint_Port` · `LampPoint_Starboard` · `LampPoint_Mast` | 좌 · 우현 · 마스트 | 밤 항해등(선택) |

### A-2. 지원 고속정 — `SUP_FastBoat`

지금: `SupportFx.BuildFastBoat`. 길이 약 **6.2m** × 폭 1.9m, 낮은 선체 · 조타실 · 앞 갑판 기관포.

- 편대 6척이 한 화면에 함께 보이므로 **실루엣이 단순하고 날렵하게**(적 고속정 `ENE_FastBoat`와 헷갈리지 않게 청록 띠 + 흰 조타실).
- **필수 계층**: `TurretPivot`(앞 갑판 기관포 선회 중심) → `Muzzle`(포구 끝, 앞 = +Z). 지금은 선회하지 않지만 붙여 두면 연결한다.
- 선미에 물보라가 나올 `WakePoint`(선택).

## B. 지원 블록 4종 (1×1 칸, 2m)

지금: `Editor/NavalSupportBlockBuilder.cs`가 갑판 받침 + 상자로 짓는다(`BLK_FireSupport` · `BLK_ReconDrone` · `BLK_EmergencyShield` · `BLK_FleetRelay`).
**크기**: 받침 1.78m × 1.78m(칸 안), 높이 1.0~1.7m. 원점 = 블록 바닥 가운데, 앞 = +Z(함수 쪽).
**단계 외형(권장)**: 지원 블록은 Lv1 → Lv3로 강화한다. 한 FBX 안에 `Visual_Level1` · `Visual_Level2` · `Visual_Level3`(같은 받침, 위가 조금씩 커지거나 늘어남)를 두면 강화할 때 바뀐다(기존 무장 블록과 같은 방식). 어려우면 1종만.

| 블록 | 하는 일 | 원하는 모습 | 단계별로 늘어날 것(권장) |
|---|---|---|---|
| 포격 지원 요청 `BLK_FireSupport` | 적이 몰린 곳에 화면 밖 순양함 포격 | 사격 지휘소: 작은 함포 사격 지휘 장치(쌍안 거리측정기) + 무전 안테나, 주황 띠 | 안테나 1 → 2 → 지휘 장치 대형화 |
| 정찰 드론 격납고 `BLK_ReconDrone` | 드론이 날아가 적을 드러내고 약점 표시 | 셔터 문 달린 작은 격납고 + 위 발사 레일에 고정익 드론, 데이터링크 돔, 연두 띠 | 레일 위 드론 1 → 2 → 3기 |
| 응급 차폐 장갑 `BLK_EmergencyShield` | 큰 피해를 받으면 3초 보호막 | 장갑 받침 위 방사기 돔(유리 `Blue black glazing` 코어) + 축전기 판 4장, 하늘색 띠 | 축전기 판 · 코어 크기 |
| 전투단 통신 중계 `BLK_FleetRelay` | 보급선 + 고속정 편대 호출 | 통신실 + 신호 마스트(가로대 · 신호기 깃발) + 접시 안테나, 옆에 보급 연락정과 대빗, 청록 띠 | 신호기 깃발 수 · 마스트 높이 |

- 블록 옆면(+X) 아래쪽에 **역할 색 띠**(`RoleMark`) 자리를 남겨 두면 카드 · 사전 색과 맞춘다(띠는 Claude가 칠해도 됨).
- 움직이는 부품 단위로 메시 합치기: 받침 / 회전 안테나(통신 중계 접시 — `SpinPivot` 이름이면 돌린다) / 나머지.

## C. 정찰 드론 — `SUP_ReconDrone`

지금: `SupportFx.BuildDrone`(게임에서 1.5배로 키움 — 최종 날개 폭 약 **3m**). 고도 9m에서 적 위를 맴돈다.

- 위에서 내려다보는 시점이라 **날개 · 꼬리 실루엣이 또렷한 고정익 무인기**(쌍꼬리 붐 또는 V꼬리). 동체 아래 센서 볼.
- 빈 노드 `LampPoint`(꼭대기 점멸등), 프로펠러는 `PropPivot`(뒤쪽 추진식, +Z축으로 돈다)이면 돌린다.

- 보급선 · 고속정 · 드론: `SupportFx`의 임시 생성 함수를 FBX 프리팹 불러오기로 바꾸고 `TransferPoint` · `Muzzle` · `LampPoint` 연결. 섬 회피 반경(보급선 반폭 + 0.4m)도 모델 폭에 맞춘다.
